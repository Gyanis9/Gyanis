# 定时器接口

## 范围

本文档描述以下接口：

- src/base/Timer.h
- src/base/Timer.cpp

适用平台：

- Ubuntu（Linux）
- Windows

---

## 模块目标

Timer 模块用于统一管理一次性与周期性任务，提供：

- 添加、取消、刷新、重置定时器。
- 条件定时器（依赖 weak_ptr 条件对象）。
- 批量提取到期回调，交由上层调度器执行。

---

## 核心结构

### Timer

字段说明：

- id：定时器唯一 ID。
- expired：到期时间点。
- interval：间隔时长。
- callback：到期回调。
- recurring：是否周期触发。

排序规则：

- 先按 expired 升序。
- 若过期时间相同，再按 id 升序，确保严格弱序与稳定行为。

## TimerManager 接口

### addTimer(interval, callback, recurring)

用途：

- 添加普通定时器。

参数：

- interval：毫秒间隔。
- callback：到期回调。
- recurring：是否周期定时器。

返回：

- 定时器 ID。

### addConditionTimer(interval, callback, weak_cond, recurring)

用途：

- 添加依赖条件对象的定时器。

行为：

- 当 weak_cond 无法锁定时，回调不会执行。

### cancel(id)

用途：

- 取消指定定时器。

返回：

- true：取消成功。
- false：未找到定时器。

日志：

- 未找到 ID 时输出中文警告日志。

### refresh(id)

用途：

- 以当前时间为基准，重置到期时间为 now + interval。

返回：

- true：刷新成功。
- false：未找到定时器。

说明：

- 当前实现已加锁，保证并发安全。

### reset(id, interval, from_now)

用途：

- 重置定时器到期时间与周期。

行为：

- 始终更新 interval 字段。
- from_now=true：expired = now + interval。
- from_now=false：expired += interval。

返回：

- true：重置成功。
- false：未找到定时器。

日志：

- 未找到 ID 时输出中文警告日志。

### getNextTimer()

用途：

- 获取下一个定时器剩余时间。

返回：

- 无定时器：milliseconds::max。
- 已有到期任务：0。
- 否则返回剩余毫秒数。

### ListExpiredCb(callbacks)

用途：

- 提取所有到期回调到 callbacks。

行为：

- 周期定时器会按 interval 重新入队。
- 一次性定时器会从映射中删除。

### hasTimer()

用途：

- 判断当前是否存在定时器。

## C++20 重构点

当前实现使用了以下现代能力：

- 统一使用 std::chrono::steady_clock 作为计时基准。
- 使用结构化初始化与更清晰的原子/锁语义。
- 使用 [[nodiscard]] 强化关键返回值调用约束。

---

## 跨平台说明（Ubuntu + Windows）

- 计时时钟：
    使用 steady_clock，避免系统时钟跳变影响定时器精度。
    在 Linux/Windows 均可稳定使用。

- 线程同步：
    使用 shared_mutex + atomic，均为标准库能力，无平台专属 API 依赖。

- 时间回退处理：
    若检测到时间回退，会执行重排并输出中文告警日志。

---

## 中文日志策略

当前模块日志以中文为主，统一格式：

- [定时器] 行为描述 | 字段: 值

示例：

- [定时器] 重置失败：未找到定时器 | id: 123
- [定时器] 检测到系统时间回退，正在重排定时器。

## 最小示例

```cpp
#include "base/Timer.h"

class DemoTimerManager final : public Gyanis::base::TimerManager
{
protected:
    void onTimerInsertedAtFront() override
    {
        // 通常用于唤醒 epoll/select 线程
    }
};

DemoTimerManager manager;

const auto id = manager.addTimer(1000, []
{
    // 每 1 秒触发一次
}, true);

manager.reset(id, 2000, true); // 从当前时刻起改为 2 秒周期
```
