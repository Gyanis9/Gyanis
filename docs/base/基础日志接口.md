# 基础日志接口

## 范围

本文档描述了以下文件中的日志 API：

- `src/base/Log.h`
- `src/base/Log.cpp`

跨平台行为（Windows 和 Linux）以及 `tests/base` 中的测试验证。

## 核心宏

### 流式宏

- `LOG_DEBUG(logger)`
- `LOG_INFO(logger)`
- `LOG_WARN(logger)`
- `LOG_ERROR(logger)`
- `LOG_FATAL(logger)`

通用形式：

- `LOG_LEVEL(logger, level)`

使用示例：

```cpp
auto logger = LOG_NAME("app.main");
logger->setLevel(Gyanis::base::LogLevel::DEBUG);

LOG_INFO(logger) << "service started";
LOG_ERROR(logger) << "code=" << 500;
```

### 格式化宏

- `LOG_FMT_DEBUG(logger, fmt, ...)`
- `LOG_FMT_INFO(logger, fmt, ...)`
- `LOG_FMT_WARN(logger, fmt, ...)`
- `LOG_FMT_ERROR(logger, fmt, ...)`
- `LOG_FMT_FATAL(logger, fmt, ...)`

通用形式：

- `LOG_FMT_LEVEL(logger, level, ...)`

使用示例：

```cpp
LOG_FMT_DEBUG(logger, "task %s retry=%d", "sync", 3);
```

### 日志器查找辅助宏

- `LOG_ROOT()`：根日志器
- `LOG_NAME(name)`：从 `LoggerManager` 获取指定名称的日志器

## 日志级别

枚举：`Gyanis::base::LogLevel::Level`

- `UNKNOW`
- `DEBUG`
- `INFO`
- `WARN`
- `ERROR`
- `FATAL`

辅助函数：

- `LogLevel::ToString(Level)`
- `LogLevel::FromString(std::string)`

## 事件与日志器 API

## LogEvent

- 构造函数接受文件名、行号、线程 ID、时间戳
- 静态方法 `LogEvent::Create(logger, level, source_location)`
- `format(const char* fmt, ...)`
- `format(const char* fmt, va_list)`
- `getFile()`、`getLine()`、`getThreadId()`、`getTime()`、`getContent()`

行为说明：

- `format(...)` 使用内部动态缓冲区策略
- `va_list` 处理对于多次 `vsnprintf` 调用是安全的

## LogEventWrap

- RAII 辅助类
- 在析构函数中通过 `logger->log(...)` 写入日志

## Logger

- `setLevel(...)` / `getLevel()`
- `addAppender(...)` / `delAppender(...)` / `clearAppenders()`
- `setFormatter(模式字符串 或 formatter 对象)`
- `log(...)` 及便捷方法 `debug/info/warn/error/fatal`

## 附加器

## StdoutLogAppender

- 将格式化输出写入 `std::cout`

## FileLogAppender

- 写入文件
- `reopen()` 刷新文件流（在日志路径中会有频率限制）

路径行为：

- 如果配置的路径包含目录部分，则会按需创建目录
- 纯文件名（例如 `"app.log"`）也支持，不会尝试创建空目录

## 格式化器与模式令牌

默认模式：

```text
%d{%Y-%m-%d %H:%M:%S}%T%t%T[%p]%T[%c]%T%f:%l%T%m%n
```

支持的令牌：

- `%d{...}`：日期时间（支持 strftime 格式）
- `%t`：线程 ID
- `%m`：消息
- `%p`：级别
- `%c`：日志器名称
- `%f`：文件名
- `%l`：行号
- `%n`：换行
- `%T`：制表符
- `%%`：字面百分号

无效或损坏的模式会被 `LogFormatter` 标记为格式化器错误。

## 跨平台说明

## 线程 ID 与时间来源

- 线程 ID：`std::hash<std::thread::id>`
- 时间戳：`std::chrono::system_clock`（秒为单位）

## 本地时间转换

- Windows：`localtime_s`
- Linux/Unix：`localtime_r`

## 同步

- 日志器/附加器管理器的锁使用 `std::mutex` 和 `std::scoped_lock`
- 本模块不需要平台相关的 pthread 头文件

## 快速集成示例

```cpp
#include "base/Log.h"

int main() {
    auto logger = LOG_NAME("demo");
    logger->setLevel(Gyanis::base::LogLevel::DEBUG);

    logger->clearAppenders();
    logger->addAppender(std::make_shared<Gyanis::base::StdoutLogAppender>());
    logger->addAppender(std::make_shared<Gyanis::base::FileLogAppender>("logs/demo.log"));

    LOG_INFO(logger) << "hello from stream API";
    LOG_FMT_WARN(logger, "warn code=%d", 42);
    return 0;
}
```
