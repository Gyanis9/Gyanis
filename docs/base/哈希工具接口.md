# 哈希工具接口

## 概述

`HashUtils` 提供以下能力：

- Murmur3 32/64 位非加密哈希
- Quick Hash 快速哈希
- Base64 编解码
- MD5/SHA1 摘要及 HMAC（MD5/SHA1/SHA256）
- 十六进制与二进制互转
- 字符串替换与分割
- 随机字符串生成

本次重构要点：

- 使用 C++20 特性：`[[nodiscard]]`、`std::rotl`、`std::endian`、`std::ranges`、`std::string_view`
- 使用 OpenSSL 现代 EVP 接口：
  - 摘要：OpenSSL 3 优先 `EVP_Q_digest`
  - HMAC：OpenSSL 3 优先 `EVP_MAC`（`HMAC` provider）
  - 为旧版 OpenSSL 保留兼容回退分支
- 异常与失败日志中文化，统一前缀为 `[哈希]`
- 兼容 Ubuntu 与 Windows（不依赖平台专有 API）

## 主要接口

头文件：`src/base/HashUtils.h`

### 1. Murmur3 与 Quick Hash

- `uint32_t murmur3_hash(const char* str, uint32_t seed = 1060627423)`
- `uint32_t murmur3_hash(const void* data, uint32_t size, uint32_t seed = 1060627423)`
- `uint64_t murmur3_hash64(const char* str, uint32_t seed = 1060627423, uint32_t seed2 = 1050126127)`
- `uint64_t murmur3_hash64(const void* data, uint32_t size, uint32_t seed = 1060627423, uint32_t seed2 = 1050126127)`
- `uint32_t quick_hash(const char* str)`
- `uint32_t quick_hash(const void* data, uint32_t size)`

说明：

- `quick_hash(const void*, size)` 已修复逐字节累计逻辑，确保与字符串版本一致。
- Murmur3 实现改为按字节读取并按小端处理，降低未对齐读取风险。

### 2. Base64

- `std::string base64encode(const std::string& data)`
- `std::string base64encode(const void* data, size_t len)`
- `std::string base64decode(const std::string& src)`

说明：

- 解码会校验长度、填充字符位置与非法字符；失败返回空字符串并记录中文告警日志。

### 3. 摘要与 HMAC

- `std::string md5sum(const void* data, size_t len)` 返回原始摘要字节
- `std::string md5sum(const std::string& data)`
- `std::string sha1sum(const void* data, size_t len)` 返回原始摘要字节
- `std::string sha1sum(const std::string& data)`
- `std::string md5(const std::string& data)` 返回十六进制文本
- `std::string sha1(const std::string& data)` 返回十六进制文本
- `std::string hmac_md5(const std::string& text, const std::string& key)` 返回原始字节
- `std::string hmac_sha1(const std::string& text, const std::string& key)` 返回原始字节
- `std::string hmac_sha256(const std::string& text, const std::string& key)` 返回原始字节

说明：

- 摘要/HMAC 计算失败时返回空字符串并输出中文错误日志。
- 若需文本输出，可配合 `hexstring_from_data` 使用。

### 4. 十六进制转换

- `void hexstring_from_data(const void* data, size_t len, char* output)`
- `std::string hexstring_from_data(const void* data, size_t len)`
- `std::string hexstring_from_data(const std::string& data)`
- `void data_from_hexstring(const char* hexstring, size_t length, void* output)`
- `std::string data_from_hexstring(const char* hexstring, size_t length)`
- `std::string data_from_hexstring(const std::string& hexstring)`

说明：

- 非法输入（奇数长度、非法字符、空缓冲区）会抛出 `std::invalid_argument`，并记录中文错误日志。

### 5. 字符串处理与随机串

- `std::string replace(const std::string& str, char find, char replaceWith)`
- `std::string replace(const std::string& str, char find, const std::string& replaceWith)`
- `std::string replace(const std::string& str, const std::string& find, const std::string& replaceWith)`
- `std::vector<std::string> split(const std::string& str, char delim, size_t max = ~0U)`
- `std::vector<std::string> split(const std::string& str, const char* delims, size_t max = ~0U)`
- `std::string random_string(size_t len, const std::string& chars = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ")`

说明：

- `random_string` 使用 `thread_local std::mt19937_64 + std::uniform_int_distribution`，替代 `rand()`。

## 平台兼容说明

- 代码仅依赖标准 C++20 与 OpenSSL 公共 API。
- 未使用 Linux/Windows 专属系统调用。
- 在 Ubuntu 与 Windows 下均可通过 CMake + OpenSSL 构建。
