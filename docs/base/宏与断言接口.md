# 宏与断言接口

## 范围

本文档描述以下接口：

- src/base/Macro.h

适用平台：

- Ubuntu（Linux）
- Windows

---

## 模块目标

Macro 模块提供两类能力：

- 分支预测提示宏：帮助编译器优化热点分支。
- 断言宏：在条件不满足时输出中文错误信息与调用栈，并触发断言。

该模块在 C++20 下引入了 source_location，用于自动采集断言触发点的文件、行号和函数名。

---

## 接口说明

### 1. LIKELY(expr)

用途：

- 提示 expr 更可能为真。

行为：

- GCC 或 Clang 下使用 builtin_expect。
- 其他编译器下退化为原表达式。

适用建议：

- 仅用于非常稳定的热点分支。

### 2. UNLIKELY(expr)

用途：

- 提示 expr 更可能为假。

行为：

- GCC 或 Clang 下使用 builtin_expect。
- 其他编译器下退化为原表达式。

适用建议：

- 常用于错误路径、参数校验失败路径。

### 3. ASSERT(expr)

用途：

- 断言表达式 expr 为真。

失败行为：

- 输出中文日志，包含表达式、文件、行号、函数。
- 输出调用栈。
- 触发 assert(expr)。

日志格式：

- 断言失败 | 表达式: ... | 文件: ... | 行号: ... | 函数: ...
- 调用栈: ...

### 4. ASSERT_MSG(expr, msg)

用途：

- 在 ASSERT 的基础上附加业务说明 msg。

失败行为：

- 与 ASSERT 一致。
- 日志中增加说明字段。

## C++20 特性

当前实现使用以下 C++20 能力：

- std::source_location

用途说明：

- 自动记录断言触发位置，避免手工拼接文件与行号信息。

---

## 跨平台说明

### Ubuntu（GCC/Clang）

- LIKELY 与 UNLIKELY 使用编译器内建分支预测提示。
- ASSERT 与 ASSERT_MSG 正常输出中文日志与调用栈。

### Windows（MSVC）

- LIKELY 与 UNLIKELY 退化为原表达式。
- ASSERT 与 ASSERT_MSG 正常输出中文日志与调用栈。

说明：

- 行为语义在两端保持一致，差异仅体现在分支预测提示是否可用。

---

## 最小示例

```cpp
#include "base/Macro.h"

int parseValue(const int value)
{
    ASSERT_MSG(value >= 0, "value 不能小于 0");

    if (LIKELY(value > 10))
    {
        return value;
    }

    if (UNLIKELY(value == 0))
    {
        return -1;
    }

    return value + 1;
}
```
